# TaskMindAI

AI-powered student productivity assistant.

## Project Goal

TaskMindAI is designed to help students manage their timetable, attendance, tasks, documents, and emails from one place with the help of AI.

## Planned Features

- User Authentication
- Student Dashboard
- Timetable Upload and AI Extraction
- Attendance Tracking
- Task Management
- AI Task Prioritization
- AI Assistant
- RAG Document Assistant
- AI Email Reply Assistant

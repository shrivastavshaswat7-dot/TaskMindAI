# Day 1 — What I Learned

## Frontend
The part of the application that the user sees and interacts with.

## Backend
The part of the application that handles logic and processes requests.

## Database
The place where application data is stored.

## API
A way for different software components to communicate with each other.

## Git
A version control system used to track changes in code.

## GitHub
An online platform where Git repositories can be stored and shared.
